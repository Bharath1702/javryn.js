# Javryn V0.5 — Verification & Hardening Plan

## 1. Executive Summary

This plan outlines the systematic verification, correctness audit, hardening, testing, benchmarking, and documentation pass for **Javryn V0.5 Explicit Parallel JavaScript**.

The milestone objective is to verify that `parallel.map()` delivers robust, deterministic, explicit CPU parallelism across an isolated reusable worker pool without violating single-threaded JavaScript main event loop semantics, memory boundaries, or prior V0.1–V0.4 runtime stability.

---

## 3. Detailed Action Items

1. **Harden `TaskManager` Worker Failure Cleanup**:
   - Add `handle_worker_failure(worker_id, error_msg, context)` to `TaskManager`.
   - Wire `WorkerResponse::Error` and `WorkerResponse::Stopped` to clean up any active tasks assigned to the failed worker.

2. **Expand Integration & Unit Test Suite**:
   - Create `tests/javascript/parallel/concurrent_ops.js`: test `Promise.all` with multiple map operations.
   - Create `tests/javascript/parallel/event_loop_responsiveness.js`: test `setTimeout` + microtask execution during parallel mapping.
   - Create `tests/javascript/parallel/serialization_matrix.js`: test all primitive & compound JS types + unsupported types.
   - Create `tests/javascript/parallel/large_input.js`: 1,000 elements map test.
   - Create `tests/javascript/parallel/closure_boundary.js`: test external closure reference error handling.
   - Update `tests/parallel_integration_tests.rs` to include all new tests.

3. **Benchmarking Suite**:
   - Enhance `tests/benchmark.rs` with benchmarks comparing sequential vs parallel (1, 2, 4, N workers) for:
     - Workload A (Light arithmetic)
     - Workload B (Array/Object transformation)
     - Workload C (CPU Fibonacci)

4. **Run Quality Gates & Measure Exact Test Counts**:
   - `cargo fmt --all -- --check`
   - `cargo check --workspace`
   - `cargo clippy --workspace --all-targets --all-features -- -D warnings`
   - `cargo test --workspace` (capture full output and count tests)
   - `cargo build --release`
   - Execute release binary manually on all example scripts.

5. **Generate Final Acceptance Report**:
   - Produce strict report adhering to prompt section 28 format.
